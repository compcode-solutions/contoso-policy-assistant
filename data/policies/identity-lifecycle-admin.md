# Identity Lifecycle Administration

Joiner, mover, and leaver jobs on the directory are Admin-operated.

- Starter accounts are provisioned from the signed offer record, not from a chat request.
- Movers lose previous group memberships the same day unless a documented exception exists.
- Leavers are disabled at end of the last working day; mailbox access passes to the named delegate only.
- Shared mailboxes are not used as a workaround for a delayed leaver.

Role changes that grant finance or identity rights need a second Admin approval.
