# Privileged System Access

Standing admin rights on production directories, payroll, and identity systems are limited to named Admin roles.

- Privileged sessions use a jump host and are session-recorded.
- Emergency break-glass accounts are sealed; each use opens a ticket within one hour.
- Quarterly access recertification is run by IT Security and signed by the system owner.
- Privileged access is not granted to supervisors as a convenience for team tasks.

This document is not a how-to for raising ordinary access requests.
